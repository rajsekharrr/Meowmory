# Meowmory

**AI that hunts down what changed.**

A persistent AI research assistant that remembers everything you've asked, searches the live web, and tells you exactly what changed since you last asked about something.

## Setup

1. Clone the repo
2. `npm install`
3. Copy `.env.example` to `.env.local` and fill in your keys
4. `npm run dev`

Your Anthropic or OpenAI API key is added in the app settings — it never touches the server storage.
